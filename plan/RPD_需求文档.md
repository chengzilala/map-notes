## 1 项目概述

- **定位**：小范围开放的轻量网页（白名单最多 30 人）。把各自高德 / 百度账号里已收藏的地点自动取到服务器，写自由备注，按「离我多远」排。
- **目标用户**：本人 + 白名单内的朋友；**每人只看到自己的数据**，不注册站点账号（用统一账户登录）、不分享、不公开查询。
- **已定的两条形态**：**一打开就是地图**；**手机也要能打开**。
- **当前状态**：已上线 `https://map.chesterlee.cn`（无口令页，打开即用）；取数 / 地图 / 距离 / 搜索 / 备注 / 窄屏全部可用。多用户改造已落地（v0.9.9）：白名单账户各自扫码绑定、各自同步，数据按 uid 隔离。

## 3 详细需求

### M1 自动取数
- **触发**：日常由服务器 `tools/server_sync.py` 每天 07:30±30min 自动跑，或在 `/admin` 点「立即同步收藏」；本机 `python3 tools/sync.py` 只作备用通道（首次弹出真实 Chrome 让你扫码，之后复用登录态）。
- **行为**：抓 `/ssr/api/cloudSync` → 取 名称/地址/经纬度/标签/备注名 → 自定义点用 `point_x/point_y`（z=20 像素）反算经纬度 → 按 `item_id` 去重写 `web/data/favorites.json`。
- **判定完成**：跑一次 ≥ 250 个点（360 条里有 82 条是收藏夹容器、无坐标，按设计跳过）；每个点有名称与坐标；重复跑不产生重复记录。
- **边界**：无坐标的点跳过并在日志里计数；接口失败**保留上一次数据**，不覆盖；新解析出的点少于旧数据一半时也拒绝覆盖（`--force` 可强制）。
- **不做**：不预纠偏坐标（实测：高德侧要原始坐标，预转会被二次纠偏）。

### M2 地图（首屏）
- 全屏地图打底，底部一个可拖起的列表抽屉（收起时露出最近 3 个）。
- 收藏点按标签着色；点标记弹出卡片：名称 / 地址 / 距离 / 标签 / 备注（可原地编辑）。
- **前置**：高德 JS API 2.0 的 Web 端 Key（个人认证免费）。没配 Key 时页面降级为「列表 + 距离」，不报错。
- **Key 的接入方式（已定，后续实现）**：Key 不再写进仓库里的 `config.js`，改为页面内提供一个输入框，由用户首次打开时自行填写，填完存本机（浏览器本地存储），之后自动复用；可随时在页面上清除/更换。**本期暂不实现，等后续版本做。**

### M3 附近排序
- 优先浏览器定位；拿不到（如手机经局域网 http 打开）就在地图上**点一下设定我的位置**，同样能排序。
- 本地 Haversine 算直线距离，不调任何接口、不耗配额。
- 列表项：名称 / 距离 / 标签 / 备注首行。
- 判定完成：有位置后列表按距离升序，最近的在第一。

### M4 搜索
- 输入即筛（防抖 200ms），匹配 名称 / 地址 / 备注 / 标签；与距离排序叠加（筛完仍按距离排）。

### M5 备注与标签
- 底部抽屉里的多行文本框，自由文本不限字数；标签只**展示**高德已有标签，不新建。
- **自动保存**：停止输入 500ms 落库；顶部只给一个「已保存」状态点；离开输入框或关页面前补一次保存。
- 备注落在 `web/data/notes.json`（`tools/serve.py` 提供读写接口），电脑与手机打开同一地址看到同一份；不再用浏览器数据库另存一份。
- 备注参与搜索；列表里显示首行摘要。

### M6 手机可访问
- 响应式：窄屏一列，按钮 ≥ 44px，无横向滚动。
- 数据来源：**部署到自己域名**（已定）。`tools/serve.py` 同时提供页面与备注接口，Caddy 反代并终止 HTTPS。HTTPS 下手机可直接用浏览器定位。局域网方式保留为离线备用。
- **访问保护（v0.9.7 定稿）**：不做口令页，也不做 Caddy Basic Auth（iOS 原生弹窗体验差）。**由统一账户登录在服务端完成鉴权，只放行本人**：
  - 页面用账户中心 Token 调 `POST /api/session`；服务端向 `https://account.chesterlee.cn/accountCenter` 发 `{action:"me"}` 取 uid。
  - uid 在白名单（`MN_OWNER_UID` + `MN_ALLOWED_UIDS`，逗号分隔，最多 30 个）内 → 签发 7 天 `mn_session` Cookie（HMAC-SHA256 签名、HttpOnly、SameSite=Lax）；不在 → 401「请先登录统一账户」。
  - **数据按 uid 隔离**（v0.9.9）：所有接口用会话里的 uid 取数据，互相看不到。
  - `/api/*` 与 `/data/*`：无有效会话 401；`/`、`/admin.html`、`assets/*` 等页面外壳与静态资源保持公开（否则登录墙打不开）。
  - `MN_SESSION_SECRET` 不配则进程内随机（重启后需重新登录）；白名单为空＝不拦（公开单用户，数据落 `local`）。
  - 备用方式保留：`MN_AUTH_HEADER=X-Auth-User`（反代注入用户头，配了优先按它判断）、`MN_LOGIN_URL=https://...`（未登录访问 html 时 302）。
  - 线上 `serve.py` 只监听 `127.0.0.1`，外部必须经 Caddy，避免绕过。
- 「添加到主屏幕」后按 App 使用（输入框 16px 防 iOS 聚焦缩放、按钮 48px）。

### M7 服务器自动同步（v0.4 新增，v0.9.9 多用户）
- **为什么**：手机上跑不了 Playwright、也没有高德登录态；高德 App 不导出收藏 → 只能由服务器抓。
- **登录（每人各自一次）**：登录统一账户后打开 `/admin` → 点「扫码登录高德」→ 服务器无头 Chrome 打开高德收藏页 → 截二维码（近似正方形 120–480px，失败退回整页）→ 页面每 2 秒刷新。手机同页打开时**长按存相册 → 高德 App 扫一扫 → 右上角「相册」**；也可用另一台设备扫。二维码与登录态都带 uid，互不覆盖。
- **登录态保存**：Playwright 持久化 profile 存服务器 `.sync-profiles/<uid>/amap|baidu/`（`.gitignore` 内、不随 `rsync` 覆盖、`/admin` 可一键清除）。用户已确认接受此风险。
- **同步（v0.9.9）**：`map-notes-sync.timer` 每小时触发一次 `sync_worker.py`：扫描「已绑定登录态、且距上次尝试 ≥ 20 小时」的用户，**串行**调 `server_sync.py --uid <uid>`，每批最多 2 个；单用户超 240 秒记一次失败。`server_sync.py` 抓 cloudSync → 去重 → 写 SQLite。也可在 `/admin` 点「立即同步收藏」手动触发（只同步自己）。
- **保护**：新解析点数少于旧数据一半时保留旧数据并记失败；单用户约 20 小时才请求 1 次。
- **失效提醒**：`sync_status`（按 uid 存 kv）记录 `ok / lastAttemptAt / lastSuccessAt / error / consecutiveFailures`；页面顶部超 72 小时标红；连续失败且配了 `FEISHU_WEBHOOK` 时推飞书（同一故障 24 小时内只推一次）。
- **判定完成**：扫码后 `/admin` 显示「高德登录态：有效」；下次 worker 跑完后 `/api/status` 的 `favorites.syncedAt` 更新且点数 ≥ 250。

## 4 UI · UX

- 一屏三件套：**地图（占大部分）→ 顶部搜索条 → 底部抽屉列表**。
- 无引导页、无设置页、无弹窗；只有一处「更新于 X 小时前」的新鲜度提示，超过 72 小时标红。
- 备注卡就地编辑，不跳页。
- 离线：页面与数据都在本机，断网仍可看列表与备注（地图瓦片除外）。

## 5 技术实现方案

- **前端**：纯静态单页，原生 HTML/CSS/JS，零构建、零框架（地图 SDK 除外）。
- **存储（v0.9.9）**：SQLite `web/data/map-notes.db`（`tools/store.py`），表 `users / favorites / notes / display / kv` 全部带 `uid`，读写一律按会话 uid；登录态与二维码按 uid 落在 `.sync-profiles/<uid>/`、`web/data/qr|login/`（`tools/paths.py`）。数据库与 profile 都在 `.gitignore` 里。
- **服务**：`tools/serve.py`（Python 标准库 `ThreadingHTTPServer`）做静态服务与按 uid 的数据接口：`GET /api/favorites`、`GET/POST /api/notes`、`GET/POST /api/display`、`GET /api/status`、`GET /api/amap|baidu/status`、`POST /api/amap|baidu/login/start`、`GET /api/amap|baidu/login/qr.png`、`POST /api/amap|baidu/logout`、`POST /api/sync/run`、`POST /api/session`、`GET /api/health`。`/data/*` 一律 404。电脑与手机访问同一个地址即同一份数据。
- **取数**：`tools/sync.py`（本机，Playwright + 真实 Chrome）保留为备用通道；日常由 `tools/sync_worker.py` 串行调度 `server_sync.py --uid <uid>` 无头抓取。`tools/amap_login.py` / `baidu_login.py` 负责出二维码与判定登录态（均按 uid）。
- **部署**：自有域名 + Caddy 反代到 `serve.py` 并终止 HTTPS；鉴权由统一账户登录完成（见 M6）；定时任务用 systemd（`map-notes.service` 常驻、`map-notes-sync.service` oneshot、`map-notes-sync.timer` 每小时）。
- **文件**：

```
map-notes/
├── web/
│   ├── index.html
│   ├── admin.html             # 扫码绑定高德 / 百度、立即同步、清除登录态（都是当前账户的）
│   ├── assets/{css,js}        # config.js（高德 Key）、app.js
│   └── data/                  # 不入库
│       ├── map-notes.db       # SQLite：收藏 / 备注 / 偏好 / 状态（按 uid）
│       ├── qr/                # 二维码（<uid>-<源>.png）
│       └── login/             # 登录状态（<uid>-<源>.json）
├── tools/
│   ├── store.py               # SQLite 数据层（按 uid）
│   ├── paths.py               # 按 uid 的 profile / 二维码 / 状态路径
│   ├── sync.py                # 本机取数（备用通道）
│   ├── sync_all.py            # 多源汇总（可带 --uid 写数据库）
│   ├── server_sync.py         # 单用户同步 + 飞书提醒
│   ├── sync_worker.py         # 串行调度：到期用户逐个同步
│   ├── amap_login.py          # 高德二维码 / 登录态
│   ├── baidu_login.py         # 百度二维码 / 登录态
│   ├── serve.py               # 静态服务 + 按 uid 的接口（不含登录页）
│   └── systemd/               # 三个 unit 模板
└── .sync-profiles/<uid>/      # 服务器上的登录态（不入库）
```

## 7 成功标准

1. 从零到能用：**一条命令 + 打开页面**，中途不需要复制粘贴任何东西。
2. 站在某地打开，**3 秒内**看到最近的 5 个收藏。
3. 写备注**不需要点保存**，关掉页面再打开还在。
4. 手机上打开可用（布局不乱、能写备注）；已在 `map.chesterlee.cn` 验收。
5. **手机上不用电脑也能更新收藏**：扫码登录一次后，服务器按周期自动更新；想立刻拉就在 `/admin` 点一下。
6. 不部署时数据不出本机；部署时数据只在自己的服务器，不接第三方。
7. **多用户互不干扰（v0.9.9）**：A 的收藏 / 备注 / 来源偏好 / 同步状态，B 完全看不到；B 重新扫码只影响 B 的登录态。

## 8 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 高德 JS API Key 未申请 | 地图不可用 | 无 Key 时降级为「列表 + 距离」，其余功能照常；Key 走页面内自行填写（见 M2 的「Key 接入方式」，后续版本实现），不再写进仓库 |
| Key 域名白名单限制 | 手机地图打不开 | 部署后把正式域名填进白名单；本地调试填 `localhost` |
| 手机 http 下浏览器禁定位 | 手机上排不了距离 | 部署后是 HTTPS，可直接定位；也可点地图设定「我在这」 |
| 手机访问 | 手机端空白 | 已上线：`https://map.chesterlee.cn`（Caddy 反代 `serve.py` + HTTPS）；局域网可用作离线备用 |
| 公网可读可写 | 备注与收藏被陌生人读写 | v0.9.7 已封：`/api/*` 与 `/data/*` 无有效会话一律 401、非本人 uid 403；页面外壳仍公开但拿不到数据 |
| 统一登录尚未接入 | 期间任何人可改备注、点「清除高德登录态」 | v0.9.7 已解决：所有写接口与 `/admin` 的接口调用都要本人会话；`/api/health` 与 `/api/session` 始终公开（不返回数据） |
| 高德登录态存在服务器 | 登录态泄露风险 | 用户已确认接受：`.sync-profiles/<uid>/` 只在服务器、`.gitignore` 内、`rsync` 排除、`/admin` 可一键清除；单用户约 20 小时仅 1 次请求 |
| 多用户同出口 IP 抓取（v0.9.9） | 被高德判定异常 | 白名单上限 30 人；串行 + 约 20 小时一次 + 随机抖动；只读收藏，不做浏览/点赞等交互模拟；观察到掉登录就降批或拉长间隔 |
| 2C2G 内存（v0.9.9） | 多个无头 Chrome 并发 OOM | `sync_worker.py` 强制串行、默认每批 2 个、单用户 240 秒超时；超时记失败不重试轰炸 |
| 登录态掉线（v0.9.9） | 该用户数据不更新 | 页面顶部超 72h 标红 + 飞书提醒；`/admin` 显示未绑定，用户重新扫码一次即可 |
| 扫码登录在手机上的体验 | 同一台手机无法「自己扫自己」 | `/admin` 写明「长按二维码存相册 → 高德 App 扫一扫 → 右上角相册」；也可换另一台设备扫 |
| 飞书 webhook 未配 | 失效无提醒 | 页面顶部仍会标红（超 72h）；补 `FEISHU_WEBHOOK` 后自动启用，同一故障 24h 内只推一次 |
| 服务器定时器未跑 | 数据不更新 | `/admin` 显示「立即同步收藏」可手动补；`sync-status.json` 记录 `lastAttemptAt / error`；定时器 `Persistent=true`，关机错过的开机后补跑 |
| 高德接口加签名 / 改字段 | 同步失败 | 保留上次数据；只解析用到的字段；`--debug` 留原始返回 |
| 浏览器清缓存 | 备注丢失 | 备注已落 `web/data/notes.json`，与浏览器缓存无关；仍建议定期整机备份 |
| 定位漂移（室内 / 车库） | 距离失真 | 显示精度；可在地图上手动改正 |
